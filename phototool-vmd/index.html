Prepare event photos

Pick the event, pick the photos – you get one zip that is ready to upload to GitHub. Nothing is uploaded anywhere by this page – everything happens on your device.

1Which event?

Only events that are already in events.js appear here.

Could not load the events. Reload the page – or select your events.js file (GitHub: events.js → Download raw file).

2Choose the photos

JPG or PNG, as many as you like (best 15–40). They are sorted by the time they were taken.

3Make the zip

Photos are resized to 1600 px, compressed, numbered 01, 02, 03 … and the hidden GPS/location data is removed.

4Upload to GitHub

  1. Unzip . Inside: an events folder and events.js.
  2. GitHub → your repo start page → Add file → Upload files.
  3. Drag in both: the events folder and events.js.
  4. Commit changes. After 1–2 minutes the album is live with a 📸 Fotos ansehen button.
